# List4U

**Aplicação Web para Gerenciamento de Listas de Supermercado e Histórico de Preços**

## Sobre o projeto

O List4U é um projeto de software que tem como objetivo facilitar a organização das compras de supermercado, permitindo que usuários gerenciem suas listas de compras, acompanhem os produtos adquiridos e registrem os preços pagos ao longo do tempo.

A proposta busca reduzir o esquecimento de produtos durante as compras e fornecer informações históricas que auxiliem o usuário no acompanhamento dos gastos.

## Objetivo da primeira versão

Desenvolver uma aplicação web com autenticação de usuários, gerenciamento de listas de compras, controle da situação dos itens e registro do histórico de preços.

## Funcionalidades planejadas

- Cadastro, autenticação e encerramento de sessão.
- Criação e gerenciamento de listas.
- Inclusão, edição, remoção e conclusão de itens.
- Registro e consulta de preços.
- Cálculo da média dos preços registrados.
- Futuro compartilhamento familiar e comparação de preços entre supermercados.

## Tecnologias previstas

- HTML, CSS e JavaScript.
- Firebase Authentication.
- Cloud Firestore.
- Git e GitHub.
